Disney hotstar app clone project

Integrated git as a source code management tool
https://github.com/santhoshawsgit/Hotstar-App.git

Integrated maven to build the project

Integrated jenkins and created a jenkins file for the project

Created a dockerfile and containerised the application and integrated it with jenkins.



To run the project, just need to put the GitHub url in the jenkins pipeline and trigger the job.

That's it the project is up and running you will see a hotstar clone app webpage.
